A useful reading order

  1. SKILL.md: candidate approval, factual sources and private voice references.
  2. scripts/build_cv.py: structured input and career-lane section ordering.
  3. scripts/render_cv.py: browser lifecycle and checked output publication.
  4. scripts/cv_checks.py: the shared PDF and posting checks.
  5. tests/: synthetic failures and actual A4/Letter exports.
